# Afterimage

Afterimage is the public, free, GPL Windows art application derived from Krita. Preserve Krita's authorship, source history and licenses. Upstream source remains the rendering/document/tool foundation, not a disposable viewer around a second image editor.

Read `module-manifest.md`. Project intent and the foundation rationale live in the shared vault under `projects/compositor` until that historical project location is deliberately migrated. The name is Afterimage.

Build for pixel artists, comic artists, glitch artists and everyday graphic composition. Judge changes through complete creative work. Frank explicitly rejected measurement-led optimization and isolated operation checklists as substitutes for thoughtful experience and architecture.

Krita owns document pixels, layers, selections, undo, color and painting. Native Afterimage tools and the Codex collaborator operate on that same owner. Cloud/local generators produce retained candidates with alpha and source provenance; they never become a second live document engine. ChatGPT subscription access uses official Codex app-server with application-owned authentication. API billing is a separate route. Local art models are an intended future provider, not an implementation requirement for the first build.

The artist and agent can work at the same time. Agent operation uses native application/document commands and document renders, equally when the window is foregrounded, backgrounded or minimized. It must not depend on desktop screenshots, take physical mouse/keyboard focus, or lock window movement. A conversation keeps its artwork attached until the artist explicitly changes it; changing tabs must not redirect pending work or the next steering message. Ordinary authorized edits may apply directly with native undo; comparisons are creative options rather than mandatory approvals. Keep images out of textual model context and make document detail queryable without sending complete large layer trees. Conversation, streaming, steering and clear human/assistant distinction are core product behavior. Verify complete neutral creative workflows starting from a blank document and new conversation.

Integrate the complete current Glitch Temple creative range, including forms, ordered processes, targeting, time/material curves, typography/symbols, palettes and reusable recipes. Tai Mei's repository is read-only input for this work. Do not modify it or contact Sazed merely to consume it. Preserve attribution and all third-party licenses. Native integration must preserve creative behavior; a menu of effects or external app launcher is not completion.

Development state belongs under ignored `.afterimage/`. Preserve the installed Compositor and all original artwork until migration and the successor's actual editing experience are verified. Do not flatten unsupported editable material silently. Build scripts must not change global Python/compiler configuration or expose credentials.
