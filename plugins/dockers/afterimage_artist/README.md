# Afterimage artist workplaces

The Pixel art and Comics dockers are native Krita workplaces. Krita remains the document, pixel, color, layer, tool, and undo owner. Users open either workplace from **Tools → Creative Workplaces**; the toggle actions preserve their saved dock layout. Docker IDs are `AfterimagePixelDocker` and `AfterimageComicDocker`.

Pixel art creates a transparent native sprite at chosen dimensions. Its controls set integer canvas zoom, Krita's pixel grid, the bundled Pixel Art brush at 1 px, eraser mode, and foreground colors from an editable saved 16-color palette. Palette reduction reads the current native projection in bounded tiles, optionally applies ordered dithering, then adds a native paint layer as one undoable edit. Source layers remain hidden underneath; alpha is retained. PNG export streams rows at original size or integer nearest-neighbor scale, either RGBA or true indexed color with up to 256 distinct color-and-alpha entries. The normal Krita Save action retains the editable KRA.

Comics creates a white 300 dpi native page with a separate transparent Artwork layer. Choose a local comic folder, save each page as KRA, and move pages into reading order with the dock's Up and Down buttons. `.afterimage-comic.json` keeps that order; the individual KRA files remain the editable originals. Opening a listed page is an explicit user action. A save joins the book only after Krita reports completion of that exact KRA file. Panel presets make editable vector frames on their own layer, and revising a preset replaces only that layer as one undoable edit. Select a region on the native canvas before adding a caption or balloon to place wrapped, fitted text there; without a selection, lettering starts near the upper-left. Captions and balloons each get their own editable vector layer, while painting remains on Artwork.

The dock exports the current page as PNG or PDF and the ordered saved pages as one PDF. Book export uses a separate offscreen Krita process, so loading a large KRA does not block painting in the artist's window. It reads and renders one saved page at a time, honors each page's native DPI and dimensions, draws bounded strips with zero PDF margins, reports page progress, and can be stopped. The PDF replaces an existing file only when every page finishes. Export reads the saved KRA snapshots; save recent edits before making a book PDF.

`afterimage_artist_core` contains the shared `ArtistNative` service and `ArtistToolGateway`. The conversation's `afterimage_artist_*` tools require the ID of its bound `KisDocument`; they never consult the active tab or change the active canvas, tool, layer, window, or input focus. Agents can save a bound page into a comic folder, list and reorder pages, place region-based lettering, and export the same ordered PDF through the native service. Direct dock controls act only on an explicit user click. Native SVG insertion adds the shape layer to the image before applying Krita's `KoShapeCreateCommand`, so shapes render, undo, and survive KRA reopen.

The focused `afterimage_artist_workflow` test creates a colored sprite, reduces it to a palette, verifies transparent original-size and 4× indexed PNGs, and reopens its editable KRA. It creates a separate three-page robot comic with artwork, frames, and lettering; waits for each native save, reopens the editable KRA files, persists and revises page order, and exports the ordered book PDF through the same gateway used by the conversation. Set `AFTERIMAGE_ARTIST_OUTPUT` to retain its artifacts. `afterimage_artist_preview` renders both dockers offscreen at 360 px and 480 px widths.

A separate retained-artwork booklet uses the rooftop-garden strip made in `.afterimage/live-api-rooftop/rooftop-garden-robot.kra`. The original stays untouched. `afterimage_rooftop_booklet` produces a corrected strip copy with its vector captions inside the top frames (`rooftop-garden-corrected.kra` and `.png`) and a `booklet/` folder with ordered `01.kra`–`03.kra`, matching PNGs, and `Rooftop Garden Robot.pdf`. Each portrait page is 512×864 at 144 dpi, retaining cropped native paint layers and its own editable vector lettering layer; the middle page also retains the separate native edit layer. The PDF has three 256×432 pt pages. The booklet's PNGs and all three rasterized PDF pages were visually reviewed for reading order, complete borders, artwork, and text. These files are local ignored evidence artifacts, not bundled sample content.

Current limits: changing a preset replaces manual edits made inside the previous Panels layer, so artists should place bespoke panel art on separate layers. Lettering is SVG text on editable vector layers rather than Krita's rich-text tool. Book PDF export uses the most recently saved version of each KRA page. Indexed PNG is available only when the finished projection contains at most 256 distinct color-and-alpha values; RGBA remains available for all others. The native animation timeline remains available in Krita, but this dock has no sprite-specific timeline controls.
