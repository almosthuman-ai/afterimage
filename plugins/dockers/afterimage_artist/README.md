# Afterimage artist workplaces

The Pixel art and Comics dockers are native Krita workplaces. Krita remains the document, pixel, color, layer, tool, and undo owner. Users open either workplace from **Tools → Creative Workplaces**; the toggle actions preserve their saved dock layout. Docker IDs are `AfterimagePixelDocker` and `AfterimageComicDocker`.

Pixel art creates a transparent native sprite at chosen dimensions. Its controls set integer canvas zoom, Krita's pixel grid, the bundled Pixel Art brush at 1 px, eraser mode, and foreground colors from an editable saved 16-color palette. Palette reduction reads the current native projection in bounded tiles, optionally applies ordered dithering, then adds a native paint layer as one undoable edit. Source layers remain hidden underneath; alpha is retained. PNG export streams rows at original size or integer nearest-neighbor scale, either RGBA or true indexed color with up to 256 distinct color-and-alpha entries. The normal Krita Save action retains the editable KRA.

Comics creates a white 300 dpi native page with a separate transparent Artwork layer. A chosen folder lists saved KRA pages; opening a listed page is an explicit user action. Panel presets make editable vector frames on their own layer. Revising a preset replaces only that panel layer in an undoable edit. Captions and balloons each get a separate editable vector layer, while painting remains on Artwork. The dock saves KRA and exports full-page PNG or 300 dpi PDF. PNG is row-streamed and PDF is rendered in bounded strips rather than materializing the full page as a QImage.

`afterimage_artist_core` contains the shared `ArtistNative` service and `ArtistToolGateway`. The conversation's four `afterimage_artist_*` tools require the ID of its bound `KisDocument`; they never consult the active tab or change the active canvas, tool, layer, window, or input focus. Direct dock controls act only on an explicit user click. Native SVG insertion adds the shape layer to the image before applying Krita's `KoShapeCreateCommand`, so shapes render, undo, and survive KRA reopen.

The focused `afterimage_artist_workflow` test creates a colored sprite, reduces it to a palette, verifies transparent original-size and 4× indexed PNGs, and reopens its editable KRA. It also creates native panel and balloon layers through the gateway, checks rendered PNG pixels, reopens their editable KRA, and exports PDF. Set `AFTERIMAGE_ARTIST_OUTPUT` to retain its artifacts. `afterimage_artist_preview` renders both dockers offscreen at 360 px and 480 px widths.

Current limits: changing a preset replaces manual edits made inside the previous Panels layer, so artists should place bespoke panel art on separate layers. Lettering placement uses coordinates and explicit line breaks; automatic balloon fitting and a book-level export are not yet present. Indexed PNG is available only when the finished projection contains at most 256 distinct color-and-alpha values; RGBA remains available for all others. The native animation timeline remains available in Krita, but this dock has no sprite-specific timeline controls.
